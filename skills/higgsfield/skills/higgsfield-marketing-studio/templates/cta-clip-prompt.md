# CTA Clip Prompt Skeleton (5s, Direct Seedance)

The CTA clip is not generated by Marketing Studio, it has no CTA format
dropdown. Render it via direct Seedance using this skeleton.

Inherits from `../../shared/higgsfield-prompt-skeletons.md` Skeleton 2 (video
prompt). Order-sensitive, do not reorder fields.

---

## Skeleton

```
[DURATION + ASPECT], [SHOT TYPE], [SUBJECT + ACTION across the duration],
[SETTING], [TIME OF DAY + LIGHTING], [CAMERA MOVEMENT], [LENS / DEPTH],
[COLOR + TEXTURE], [AUDIO INTENT, optional], [PRODUCT VISIBILITY],
[WHAT TO EXCLUDE]
```

## CTA copy rules (HARD)

The literal CTA dialogue (the bit in quotes inside the prompt) MUST pass
`content-engine` + `humanizer` BEFORE being inserted into the prompt.

### Banned in CTA dialogue

- "Game-changer", "10x", "transform your life", "unlock your potential"
- "Crushing it", "killing it", "level up", "secret sauce"
- Refund / money-back / "satisfaction guaranteed"
- Outcome promises ("get 10x results", "guaranteed success")
- Casual drop-in invites ("come say hi", "swing past")
- Em dashes (use commas or periods inside the dialogue too)

### Approved CTA shapes (action verb + plain destination)

- "Click the link below to shop now."
- "Tap below to start a free trial."
- "Link in bio to book a call."
- "Order now, link below."
- "Comment <KEYWORD> and we will send the link."
- "Get yours, link below, ships today."

### Approved tone

- Conversational, not corporate.
- One CTA action per clip, no double-CTAs.
- Avatar's body language matches the CTA energy (calm for retention,
  warm for conversion, confident for awareness).

## Pre-render checklist

Before submitting the CTA prompt to Seedance:

- [ ] CTA dialogue passed `content-engine` voice gate.
- [ ] CTA dialogue passed `humanizer` slop gate.
- [ ] `@product` Element is uploaded if you're using product tagging
      (see `../../shared/element-tagging.md`).
- [ ] Same avatar selected as clips 1, 2, 4 (face continuity).
- [ ] Resolution matches the stitch (720p cheap_test, 1080p full_stitch).
- [ ] Aspect = 9:16.
- [ ] Duration = 5s.

---

## Common CTA failures

| Symptom | Fix |
|---------|-----|
| Avatar's mouth doesn't say the CTA cleanly | Re-render with shorter dialogue (under 7 words is safest at 5s) |
| Avatar's hands flail awkwardly during CTA | Add explicit hand instruction: "free hand resting at side" |
| AI inserts an em dash in spoken CTA | Re-prompt with EXCLUDE em dashes in dialogue |
| CTA voice doesn't match clips 1-4 voice | Use CapCut Change Voice in post to match, don't burn another Seedance render |
| Product not visible in CTA | Add explicit "product label visible facing camera" + use `@product` Element |
| CTA feels rushed | Re-render at 6-7s duration, OR speed adjust to 90% in CapCut |
